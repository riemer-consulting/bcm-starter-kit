# Support

BCM Starter Kit is a community-maintained open source project, provided free
of charge under the Apache License 2.0. Please read this document before
asking for help — it sets expectations for what kind of support is and is not
available.

## What this project is

A free, open source software tool. Nothing more.

## What this project is not

- **Not a paid product.** There is no support contract, no service-level
  agreement, and no guaranteed response time.
- **Not a consulting service.** Neither the maintainer nor this repository
  provides Business Continuity Management consulting, advice on how to
  interpret your specific business impact analysis results, or help
  designing your organization's continuity strategy. The application is a
  structuring tool; the BCM expertise to use it well has to come from you or
  your own advisors.
- **Not staffed.** This is maintained on a best-effort, volunteer basis
  alongside other work. Issues may sit unanswered for a while — that isn't
  personal.

## Where to get help

- **Something broken? Found a bug?** Open a [GitHub Issue](../../issues).
  There are no issue templates in this repository, so please include the
  following yourself: the application version (in-app **About** dialog), your
  browser and its version, what you expected, what happened instead, and the
  steps to reproduce it. If an import is involved, a minimal example file
  helps a great deal.
- **Have an idea or a question about a feature?** Open a
  [GitHub Discussion](../../discussions) if enabled, or a regular
  [issue](../../issues). Please read
  [CONTRIBUTING.md](CONTRIBUTING.md) first — this project is intentionally
  feature-complete, and most feature requests will be declined rather than
  silently ignored, but they are still worth discussing.
- **General "how do I…" questions?** Check [`docs/user-guide.md`](docs/user-guide.md)
  and [`docs/faq.md`](docs/faq.md) first. If your question isn't answered
  there, a Discussion (if enabled) is the right place — it keeps the answer
  visible for the next person with the same question.
- **Security issue?** Do **not** open a public issue — see
  [SECURITY.md](SECURITY.md) instead.

## Before you ask

1. Check the [FAQ](docs/faq.md) — many common questions are answered there.
2. Check whether an existing issue already covers it.
3. Run the built-in self-tests (**Ctrl+Alt+T** in the app) if you suspect a
   logic bug, and include the result in your report (it reports the total and
   the number passed — 57 of 57 is the expected outcome in 2.2.0).
4. Make sure you're on the latest 2.x release — see [SECURITY.md](SECURITY.md)
   for supported versions.

Thank you for your patience and for contributing to keeping this a useful
tool for everyone who relies on it.
