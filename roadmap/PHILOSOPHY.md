# Produktphilosophie

Das BCM Starter Kit ist kein Formulargenerator.

Es unterstützt Menschen, die Verantwortung für die Handlungsfähigkeit eines Unternehmens tragen.

## Grundsätze

- Offline First
- Single File
- Evolution statt Neubau
- Qualität vor Quantität
- Deterministische Fachlogik
- Keine stillen Datenverluste
- KI niemals verpflichtend
- Transparenz vor Automatisierung
