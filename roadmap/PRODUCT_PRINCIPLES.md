# Produktprinzipien

## Fachlich
- Dokumentationsqualität getrennt von Risiko
- Konsistenz getrennt von Managemententscheidung
- Keine Scheingenauigkeit
- Nachvollziehbarkeit vor Automatisierung

## Technisch
- Additive Migrationen
- Rückwärtskompatibilität
- Keine Breaking Changes
- Vollständige Roundtrip-Tests
- Import darf niemals Daten verlieren
