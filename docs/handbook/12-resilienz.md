# 12. Resilienz-Check

## Wofür ist diese Funktion da?

Eine feste 12-Punkte-Checkliste, mit der Sie schnell erkennen, wie robust
ein Prozess grundsätzlich aufgestellt ist — unabhängig von der konkreten
Notbetriebsplanung. Aus roten und gelben Punkten lassen sich direkt
Maßnahmen ableiten.

## Wo finde ich ihn?

Im Reiter **Resilienz-Check** jeder Prozessakte.

## Die zwölf Punkte

Vertretung vorhanden, Prozess dokumentiert, Offline-Unterlagen vorhanden,
Papierprozess möglich, Kontaktdaten aktuell, Lieferantenalternativen
vorhanden, IT-Alternative vorhanden, Schulung durchgeführt, Notbetrieb
getestet, Kommunikationsweg definiert, Entscheidungskompetenz klar,
Wiederanlauf beschrieben.

## So gehe ich vor

Bewerten Sie jeden Punkt mit einer Ampel:

- **Grün** — erfüllt.
- **Gelb** — teilweise erfüllt oder unklar.
- **Rot** — nicht erfüllt.

Zu jedem Punkt kann ein Kommentar/eine Begründung erfasst werden. Zu
vielen Punkten zeigt das Starter Kit außerdem eine kurze **Empfehlung**
(💡), die typische nächste Schritte vorschlägt.

## Maßnahmen aus Checks erzeugen

Über den Knopf **Maßnahmen aus Checks erzeugen** lässt das Starter Kit
für alle roten (und optional gelben) Punkte automatisch
Maßnahmen-Vorschläge im Maßnahmenkatalog anlegen (siehe
[Kapitel 15](15-massnahmenmanagement.md)). Das ersetzt nicht die
inhaltliche Prüfung — die vorgeschlagenen Maßnahmen sollten Sie
anschließend konkretisieren, priorisieren und terminieren.

## Was das Starter Kit automatisch macht

Oben im Reiter zählt es die Ampeln zusammen (z. B. "2 rot · 3 gelb · 7
grün") — eine schnelle Übersicht, ohne dass daraus ein einzelner
Gesamt-Score gebildet wird.

## Was ich selbst entscheiden muss

Die Einstufung jedes Punkts ist eine fachliche Einschätzung. Die
Empfehlungstexte sind allgemeine Hinweise, keine auf Ihren Prozess
zugeschnittene Beratung.

## Beispiel aus der Praxis

Prozess "Warenausgang": "IT-Alternative vorhanden" — Rot, Kommentar
"Kein Ausweichsystem für das Auftragssystem vorhanden". Über "Maßnahmen
aus Checks erzeugen" entsteht daraus automatisch ein Maßnahmen-Entwurf
"IT-Alternative vorhanden schaffen", der anschließend im
Maßnahmenkatalog konkretisiert wird.

## Typische Fehler

- Alle Punkte pauschal auf Grün setzen, ohne die Frage wirklich zu
  prüfen.
- Rote Punkte erkennen, aber nie in eine Maßnahme überführen.
