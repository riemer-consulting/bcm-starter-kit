# Documentation Images

This directory is reserved for images referenced from files in `docs/`
(diagrams, annotated screenshots, etc.). It is currently empty — none of the
documentation written for the initial 2.1.0 release required an image beyond
what's already covered in `assets/screenshots/`.

Add images here as needed and reference them with relative paths from the
referencing file, e.g. an image named `example.png` placed in this folder
would be referenced as `images/example.png` from a file in `docs/`.
